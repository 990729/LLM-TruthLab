# LLM-TruthLab — 开源 API 中转站一键鉴假 & 智商体检工具

> **打开即用（Windows 单文件 `.exe`，无需安装 Python），填上中转站地址、Key 和模型名，一键测出有没有掺水、有没有降智、背后最可能是什么模型，直接出 10 秒能看懂的大白话报告！**

---

## 为什么做这个工具？

买第三方大模型 API 中转站时，最怕遇到：
- **挂羊头卖狗肉**：卖高价旗舰，背后偷偷换成便宜模型或同系轻量版；
- **降智与暗砍**：重度量化、偷降推理深度、截断上下文、把高清图压缩糊了省钱；
- **假账单与加价**：按贵模型词表虚报 Token、暗箱高倍率扣费；
- **白天真货晚上掺水**：短消息给真货、长代码或高峰期偷偷切到便宜池。

**LLM-TruthLab** 坚持「不轻信接口自报的模型名字，只看实打实的证据」，同时把枯燥的技术参数自动翻译成**普通人 10 秒看懂的大白话结论**。

## 核心亮点

- **开箱即食，零环境依赖**：Windows 10/11 64 位直接双击 `LLM-TruthLab.exe` 运行，自动适配各种屏幕分辨率与只读目录权限，API Key 仅留在本地内存，绝不上传、绝不落盘明文。
- **默认生成「大白话体检结论」+「最可能真实模型」**：测完直接告诉你能不能放心用、有没有毛病、背后最可能是什么模型（覆盖 2026 最新主流模型线），还自带**中转暗倍率计算器**与**预算上限熔断器**。
- **多维度防掺水体检**：
  - 官方加密思考签名 1 字节篡改验签、拆字习惯核验（抓假账单）、正则改词洗白诱饵、缓存物理加速与号池粘性、打字速度与假流式检测、1024² 高清微缩图防压缩、5 轮对话防失忆、并行工具调用自愈等。
  - 针对 2026 新代模型做了真实场景校准：**不会**因为中转站自带常规防封提示词或新模型不支持调温度而乱报假货。
- **10 维 31 类防背题动态智商测评（题量翻倍，并发加速）**：
  - 内置 **31 种完全不同的动态出题引擎**（含辛普森悖论、调和均速陷阱、五元唯一解逻辑约束、DAG 关键路径排程、中文财务大写超额累进计算、容斥计数、大指数模幂、反贪心加权最短路、Python 闭包与可变默认参数追踪、AST 沙箱可执行动态规划 & 表达式解析器 & 精准外科代码补丁、纯内存只读 SQLite 多表 JOIN & GROUP BY HAVING SQL、三维骰子 8 步滚动姿态推演、6×6 传送门网格、新旧双文档冲突防幻觉、长文多跳寻针等）。
  - 每次按随机 Seed 现做现判，彻底杜绝背题刷分；**快速 17 题 / 标准 31 题 / 深度 34 题**，支持一键 **「纯测智商 (34题)」** 预设，4 路并发加速不拖时间！
- **六大实用工具台**：
  1. **一键查真假**（单站体检 + 零花费模拟演示 + 战报 PNG/HTML/Markdown 导出）
  2. **双端抓套娃**（同站高价模型 vs 便宜模型同台 PK，专抓改名套娃）
  3. **多站红黑榜**（一次横评 2–12 个渠道，生成同源相似度矩阵）
  4. **本地防偷换代理**（Cursor / Claude Code 接本地端口，零额外花费边写代码边监看防偷换）
  5. **定时盯盘告警**（支持飞书 / 钉钉 / 企业微信 / Discord Webhook）
  6. **历史对比与基线库**（支持全量 ZIP 一键备份与导入还原）

## 下载与运行

### 方式一：直接下载 EXE（推荐）
前往本仓库右侧 **Releases** 页面下载最新 `LLM-TruthLab.exe`，双击直接打开即可（无需安装任何运行库；如 Windows SmartScreen 提示未知发布者，点「更多信息 → 仍要运行」即可，全开源代码可自行审查或从源码编译）。

### 方式二：源码运行 / 自行打包 EXE
```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt

# 直接运行桌面版
.\.venv\Scripts\python app.py

# 自行重新打包单文件 EXE（自动先跑全部自动化测试）
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```
